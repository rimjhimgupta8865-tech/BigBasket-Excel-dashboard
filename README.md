# BigBasket-Excel-dashboard

The BigBasket Data Analysis project focuses on analyzing product and sales-related data to identify meaningful business patterns and insights. The project was developed using Microsoft Excel, with an emphasis on data cleaning, transformation, analysis, and dashboard creation.

The dataset was processed to organize and prepare the raw information for analysis. Various Excel functions and techniques were used to handle the data efficiently, including formulas, Pivot Tables, filtering, sorting, and data summarization.

The analysis focuses on product categories, product performance, pricing patterns, availability, and other relevant business attributes. Pivot Tables and visualizations were used to summarize the data and make important trends easier to understand.

An interactive Excel dashboard was created to present key findings in a clear and professional format. The dashboard helps users quickly understand important metrics, compare categories, identify product-level patterns, and support data-driven business decisions.

This project demonstrates practical skills in Microsoft Excel, data cleaning, data organization, Pivot Tables, data analysis, dashboard development, and business insight generation. It also showcases the ability to convert raw business data into structured information that can be used for reporting and decision-making.

**Tools & Skills:** Microsoft Excel, Data Cleaning, Excel Formulas, Pivot Tables, Data Analysis, Dashboard Development, Data Visualization, Business Insights.
